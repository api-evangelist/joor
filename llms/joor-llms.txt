# JOOR

> JOOR is a New York-based B2B wholesale fashion commerce platform and digital marketplace (founded 2010) that connects fashion brands with retailers to run wholesale end to end — online linesheets, lookbooks, virtual showrooms, order management, JOOR Pay, and JOOR Passport. Its production platform is fronted by a Kong API gateway and secured with Keycloak-based OpenID Connect. API access is partner/integration-oriented; JOOR does not run a self-serve public developer portal.
